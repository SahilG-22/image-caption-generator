# AI-Based Image Caption Generator and Accessibility Assistant

A Python-based accessibility application that generates natural-language
captions for uploaded images using a pre-trained image captioning model
and reads the generated caption aloud using text-to-speech.

## Planned Technology

- Python
- PyTorch
- Hugging Face Transformers
- BLIP
- Pillow
- Streamlit
- pyttsx3
- pytest

## Project Structure

```text
src/captioning/   - Image captioning model
src/processing/   - Image preprocessing
src/ui/           - Streamlit interface
src/utils/        - Utilities and text-to-speech
tests/            - Tests
docs/             - Documentation
```
